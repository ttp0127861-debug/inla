# INLA-S static frontend

Source design: [INLA-S Figma](https://www.figma.com/design/SFBcfYMWGv3tjAfHTfonAX/INLA-S)

The app opens on AUTH-01 (`/`). Sidebar links follow the prototype: Tổng quan, Báo giá, Công việc, Khách hàng, Báo cáo, Quản trị.

Role dashboards DASH-02 … DASH-07 are linked from the admin overview at `/dashboard/admin`.
Shared overlays (SHR) are opened from the action that uses them, and listed at `/shared/states`.
